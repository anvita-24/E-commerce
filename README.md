# E-Commerce Website

A full-stack E-Commerce website built using

- React.js
- Node.js
- Express.js
- MongoDB

## Features

- User Authentication
- Product Listing
- Product Details
- Shopping Cart
- Login & Signup
- MongoDB Database

## Tech Stack

Frontend
- React
- Material UI

Backend
- Express
- Node
- MongoDB

## Installation

Clone

git clone <repo-url>

Install frontend

cd client
npm install

Install backend

cd ../server
npm install

Run Backend

npm start

Run Frontend

npm start
